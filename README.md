# RadiologyGO

Aplicación móvil educativa para aprender y practicar posicionamiento radiológico.

## Tecnologías

- React Native con Expo
- TypeScript
- Expo Router

## Requisitos

- Node.js LTS
- npm
- Expo Go instalado en un dispositivo iOS o Android

## Ejecutar el proyecto

```bash
npm install
npx expo start
```

Escanea el código QR con Expo Go en Android o con la cámara del iPhone. El teléfono y la computadora deben estar conectados a la misma red Wi-Fi.

Si la red local impide la conexión, inicia Expo con túnel:

```bash
npx expo start --tunnel
```

## Estado actual

Esta primera versión incluye solamente una pantalla de bienvenida y una pantalla principal provisional. No incluye autenticación, Firebase, inteligencia artificial ni base de datos.
