# Audio de RadiologyGO

Coloca aquí únicamente pistas originales o con licencia compatible.

Nombres sugeridos:

- `background-music.mp3`
- `answer-correct.wav`
- `answer-incorrect.wav`
- `challenge-complete.wav`
- `badge-unlocked.wav`
- `verification-complete.wav`

Después conecta cada archivo en `src/constants/audioAssets.ts` mediante `require(...)`.
